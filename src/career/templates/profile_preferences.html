Title keywords

A listing is only shown if its title contains every word of one of these, ignoring seniority words like "Senior" or "Lead" — so "DevOps Engineer" matches "Senior DevOps Engineer" but not "Database Engineer". Each is also its own Reed search, so with none set no jobs are searched for.

{{ tag_editor(profile.preferences.desired_titles, "/profile/preferences/title-keywords", "e.g. Platform Engineer") }}
Description keywords · optional

A listing must mention at least one of these in its description (or title). Reed only gives a short snippet of the advert, so a role that mentions one further down its full advert can still be excluded.

{{ tag_editor(profile.preferences.required_keywords, "/profile/preferences/description-keywords", "e.g. Azure") }}
Desired locations · optional

Not a filter — a listing whose location mentions one of these ranks a little higher. Use the distance setting below to exclude by location.

{{ tag_editor(profile.preferences.desired_locations, "/profile/preferences/locations", "e.g. Southampton") }}
Excluded companies · optional

Listings from these companies are never shown.

{{ tag_editor(profile.preferences.excluded_companies, "/profile/preferences/excluded-companies", "e.g. Acme") }}
Work arrangement, salary and distance

"Remote or hybrid" excludes only listings that say they're on-site; "Fully remote only" excludes anything that doesn't say it's remote.

Salary and distance only exclude a listing when the source actually states a salary, or the listing's location is one of a small list of UK towns/cities this app recognises — most aren't, and an unrecognised one is never excluded on that account. A location naming a country or major city outside the UK (Germany, Berlin, Zürich, Paris…) counts as too far, but a small foreign town the app doesn't know still gets through.
